AVANCE NABLA - Extensión del visor 3D de Trimble Connect
=========================================================

Archivos (se suben TODOS, sueltos, a la raíz del repositorio):
  index.html  app.js  logica.js  config.js  manifest.json  icono.png
  ayuda.html  msal-browser.min.js  LEEME.txt

1) PUBLICAR EN GITHUB PAGES (una sola vez)
  a. github.com -> botón "+" (arriba a la derecha) -> New repository.
     Repository name: avance-nabla   |  Public  |  Create repository.
  b. En la página del repositorio: "uploading an existing file".
     Arrastra todos los archivos de este zip (no la carpeta) -> Commit changes.
  c. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, carpeta / (root) -> Save.
  d. Espera 1-2 minutos y abre:  https://nablaacero.github.io/avance-nabla/manifest.json
     Si se ve el texto del manifiesto, está publicado.

2) REGISTRAR EN TRIMBLE CONNECT (administrador del proyecto, una vez por proyecto)
  a. Abre el proyecto en Trimble Connect desde el navegador (web.connect.trimble.com).
  b. Configuración del proyecto -> Extensiones (en algunas versiones: "Apps & Capabilities" -> Add Custom).
  c. Pega:  https://nablaacero.github.io/avance-nabla/manifest.json   -> Agregar -> actívala.
  d. Abre el visor 3D: aparece el panel "Avance NABLA" en las extensiones del lado derecho.

3) USO MIENTRAS TI HACE EL REGISTRO (modo CSV)
  a. SharePoint -> lista "Avance de produccion" -> Exportar -> Exportar a CSV.
  b. En el panel: Origen = "Archivo CSV", elige el archivo, revisa el número de proyecto
     y presiona "Colorear avance".

4) CUANDO TI ENTREGUE EL ID DE APLICACIÓN (modo en línea)
  a. En GitHub abre config.js -> lápiz (Edit) -> pega el Id. de aplicación en  clientId: "..."
  b. Commit changes. Espera 1-2 minutos y recarga Trimble Connect.
  c. En el panel: Origen = "Lista de SharePoint". La primera vez pide iniciar sesión de Microsoft
     (si el navegador bloquea la ventana emergente, permítela para connect.trimble.com).
     Se actualiza solo cada 5 minutos mientras el panel está abierto.

COLORES: amarillo Armado · naranja Pintura · azul Despacho · verde Montaje · gris sin avance.
Las piezas sin marca reconocida quedan en gris transparente. Los colores solo cambian la vista.

SI DICE "No encontré marcas": selecciona una pieza en el modelo, abre "Diagnóstico" en el panel,
presiona "Ver propiedades de la selección" y envía una captura; la marca se configura en
config.js -> propiedadesMarca.
